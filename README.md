# Adrien Lachambre — portfolio

Personal portfolio, project showcase and shadcn component registry for [adrienlachambre.com](https://adrienlachambre.com).

## Stack

- Next.js 16 and React 19
- TypeScript and Tailwind CSS v4
- shadcn/ui and MDX
- Vitest, pnpm and Vercel

## Development

```bash
pnpm install
pnpm dev
```

The local development origin is `https://ncdai.localhost`. Environment variables are documented in `.env.example`.

Useful checks:

```bash
pnpm check-types
pnpm lint
pnpm test:run
pnpm build
```
